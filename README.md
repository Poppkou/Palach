# Железный Палач

Быстрый 3D-шутер для телефона в средневековом аду: щит с парированием, цеп и казни, рывок щитом, волны демонов и Тиран каждую 5-ю волну.

**Играть:** https://poppkou.github.io/Palach/ (держите телефон горизонтально; на iPhone — «Поделиться → На экран Домой» для полноэкранного режима).

Управление на ПК: WASD — движение, мышь — обзор и огонь, ПКМ/C — щит, Пробел — рывок, E — цеп, Q — смена оружия, Esc — пауза.

Графика: процедурные текстуры с картами нормалей, тени, bloom, анимированная лава и небо, частицы огня и крови. Качество (низкое/среднее/высокое) переключается в настройках.

Исходник — `game.html` (тело артефакта); `build.sh` оборачивает его в `index.html` для GitHub Pages. Three.js r128.
