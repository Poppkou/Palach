# Железный Палач

Быстрый 3D-шутер для телефона в средневековом аду. Два режима:

- **История** «Пепел Ордена», глава I: долина Пепельного Брода, деревня, Мёртвый лес, Огненный разлом, Святилище и Цитадель. Сюжет с диалогами, задания, три печати, мини-карта, маркер цели, тайники и точки сохранения. Финальный босс — Князь Пепла.
- **Арена**: бесконечные волны демонов, Тиран каждую 5-ю волну, рекорд очков.

**Играть в браузере:** https://poppkou.github.io/Palach/ (держите телефон горизонтально).
**APK для Android:** см. раздел Releases или соберите сами (ниже).

Управление на ПК: WASD — движение, мышь — обзор и огонь, ПКМ/C — щит, Пробел — рывок, E — цеп, Q — смена оружия, Esc — пауза.

## Оптимизация
Качество выбирается автоматически по памяти, ядрам и видеочипу: на бюджетных телефонах без постобработки и теней, с MSAA и упрощённым освещением. Во время игры разрешение плавно подстраивается под FPS, а если и этого мало, отключаются эффекты. В настройках есть ручной выбор графики, режим 30 FPS и отключение тряски экрана.

## Сборка
- `node build.js` собирает `src/` в `game.html` (артефакт), `index.html` (GitHub Pages) и `www/` (офлайн-версия для APK).
- APK: `npm install`, затем `npm run apk` (нужны JDK 21 и Android SDK; путь к SDK в `android/local.properties`). Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.
